# P4 — Agents inventory

## Goal

Inventory available agents, skills, and MCP tools that can serve later phases.

## Steps

1. List local skills (repo `.claude/skills`, user `~/.claude/skills`, `~/.cursor/skills`, `~/.agents/skills` as present).
2. List MCP servers/tools relevant to: architecture, GitHub, Vercel, browser, memory, swarm.
3. Map roles needed for end-state (architect, planner, coder, tester, reviewer, deploy).
4. Write `.agent/agents-inventory.md` with: available | missing | substitute.

## STOP / CONTINUE

- **STOP:** Inventory file missing.
- **CONTINUE:** Inventory written; gaps noted (do not invent fake tools).

## Outputs

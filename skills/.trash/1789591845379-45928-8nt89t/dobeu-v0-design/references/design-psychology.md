# Ethical persuasion checklist for UI (Dobeu)

Use these as structural design moves, not dark patterns. Every item must be
truthful and serve the user as well as the business.

## Hierarchy & attention
- One focal point per view. Establish a clear 1st → 2nd → 3rd read order.
- Hick's Law: fewer choices = faster decisions. One primary CTA; demote the rest.
- Von Restorff (isolation): the element that differs is remembered. Reserve amber
  for the single most important action so it stands out on the dark canvas.
- Anchoring: the first/largest number or option frames everything after it
  (pricing tiers, "from $X", comparison tables).

## Trust & evidence
- Social proof: logos, counts, testimonials, results — only real ones.
- Authority: credentials, "building since 2019", verifiable specifics.
- Pratfall effect: an honest limitation ("I take few clients at a time") can
  increase trust more than false perfection.

## Motion & momentum (BJ Fogg: Behavior = Motivation × Ability × Prompt)
- Lower activation energy: pre-fill, templates, one-click starts, short forms.
- Goal-gradient / progress: show steps and "almost there" on multi-step flows.
- Zeigarnik: a visible incomplete state (e.g., setup checklist) pulls completion.

## Framing & value
- Loss aversion / framing: emphasize what's gained or avoided, truthfully.
- Mental accounting: "$X/day" can read easier than "$Y/month" — same price.
- Contrast: show a clear before/after so improvement is vivid.

## Memory
- Peak-End rule: invest in one delightful peak and a clean, reassuring ending
  (success screens, confirmations, thoughtful empty states).

## Guardrails
- No fake scarcity, fake urgency, forced continuity, or confirm-shaming.
- Accessibility is non-negotiable; persuasion never overrides clarity or consent.
